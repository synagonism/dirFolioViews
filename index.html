overview

description::
· this directory-(dirFolioViews) contains my FolioViewsMcs-worldview which I converted to HitpMcs-format.
· FolioViews is a-propriety system. I converted to my HitpMcs because it is free and you don't-need a-special software to view it.
· FolioViewsMcs are heavily EXPERIMENTAL, full of inconsistencies and not intended for publishing. I publish them because they contain the-evolution of my thought and 'infinite' working hours.

FolioViews-Hitp-Mcs evaluation::
· FolioViewsMcs evaluation:
+ wysiwyg editing,
+ search: can display ONLY search results (records with hits, RH).
+ search: finds records(chunks of texts) that contain misc words,
+ search: it can-search only within chunks of text: filds, groups, highliters, levels,
+ it has query-links: you can-go to a-location of a-unique-name,
+ it can-manage very big binary documents (all infobases here, are ONE FolioViews file),
+ it has program-links,
+ in many concepts, contains the-EVOLUTION of my thought,

- private application,
- no Unicode support,
- search: separates names with (-),
- search: separates names with greek-letter (χ),
- find-and-replace: does not work on links in wysiwyg binary-file,
- the-textfiles (fff) of its documents written in propriety-language are-not accessible directly as in Html.
- a-lot of information is-written in Greek language,
- NOT intended for publishing,

· HitpMcs evaluation:
+ public application,
+ Unicode support,
+ preview links,
+ shows the-main-name of a-name,
+ double-clicks select names, not words, and query them,
- no wysiwyg editing,
- big text-documents are-not-managed easily by browsers,
